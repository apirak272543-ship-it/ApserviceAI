GitHub (Direct API — ทำงานทันที)

เชื่อมต่อ GitHub API ตรงจากเบราว์เซอร์เลย ไม่ผ่าน Supabase, ฐานข้อมูลงาน, คิวงาน หรือ Agent ตัวกลางใดๆ ต้องใช้ Personal Access Token (แนะนำ Fine-grained token จำกัดสิทธิ์เฉพาะรีโพนี้) — Token จะถูกเก็บไว้ในเครื่องนี้เท่านั้น อย่าแชร์สกรีนช็อตหรือไฟล์ export ที่มี Token ติดไปด้วย
ตั้งค่าครบแล้วแค่คุยในแชตตามปกติ เช่น "ช่วยอ่านไฟล์ index.html แล้วแก้บั๊ก X" AI จะเรียกใช้เครื่องมือ GitHub เอง (อ่าน/แก้ไฟล์/ดู commit) และ commit ให้ทันที โดยไม่ใช้คิวหรือ Runner ภายนอก
